# Password Generator – GUI Based Application

This is a GUI-based Password Generator project that I developed using Python and Tkinter. It helps users generate random passwords by choosing different character types and password lengths.

# Features

- Generate random passwords
- Select password length from 4 to 64 characters
- Include uppercase letters (A-Z)
- Include lowercase letters (a-z)
- Include numbers (0-9)
- Include special characters
- Copy generated passwords to clipboard
- Simple and easy-to-use interface
- Input validation

# Technologies Used

- Python
- Tkinter
- String Module
- Secrets Module

# What I Learned

- Creating GUI-based applications using Tkinter.
- Using the secrets module for random password generation.
- Working with checkboxes and buttons.
- Copying text to the clipboard.
- Handling user input and validation.
